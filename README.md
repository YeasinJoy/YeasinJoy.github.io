# Yeasin Morshed Joy — Software Engineering & AI/ML Portfolio

A modern, multi-page portfolio website showcasing software engineering projects, explainable AI research, web platforms, and academic background.

Built with semantic HTML5, modern CSS3 (Linear/Vercel design system), and vanilla JavaScript.

---

## 🧭 Multi-Page Structure

- **Home (`index.html`)**: High-impact introduction, featured engineering systems, background snapshot, and quick CTAs.
- **Projects (`projects.html`)**: Interactive catalog of all 8 production and research projects with category filters (*AI & Machine Learning*, *Full-Stack & Web*, *Embedded Systems*).
- **About & Experience (`about.html`)**: In-depth professional background, Web Development internship at GAOTek Inc., B.Sc. in Computer Science & Engineering at the University of Asia Pacific, and categorized technical skillsets.
- **Contact (`contact.html`)**: Direct contact channels (Email, LinkedIn, GitHub, CV download) and a direct message creator.

---

## 🎨 Key Features

- **Modern Developer Aesthetic**: Minimalist dark slate palette (`#09090b`), subtle technical micro-grid, 1px border lines, and Geist typography.
- **Light & Dark Mode**: Persistent theme switcher using `localStorage` and system preference detection.
- **Interactive Project Filtering**: Instant domain filtering with zero page reload.
- **Zero Heavy Frameworks**: Ultra-fast load times, zero build steps, and full native browser support.
- **GitHub Pages Ready**: Native compatibility with GitHub Pages.

---

## 🚀 Run Locally

```bash
# Clone the repository
git clone https://github.com/YeasinJoy/YeasinJoy.github.io.git
cd YeasinJoy.github.io

# Open index.html directly in any browser or run a simple local server
python -m http.server 8080
```
Then visit `http://localhost:8080` in your browser.
