# Yeasin Morshed Joy — Portfolio

Personal portfolio website built with HTML, CSS and JavaScript.

## Run locally

Open `index.html` in your browser.

## Before publishing

Replace:
- `assets/profile.jpg` with your professional photo
- `assets/cv.pdf` with your CV
- `your-email@example.com` with your real email
- the LinkedIn placeholder with your real LinkedIn profile
- the Case Study `#` link when your final-year project repository/demo is ready

## GitHub Pages

Recommended repository name:

`yeasinjoy.github.io`

Then publish the `main` branch from the repository's Pages settings.
